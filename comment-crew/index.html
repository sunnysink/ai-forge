NO REPOS SHOWING · empty picker · can't find my repository · list is blank
This one catches almost everyone, and it is a two minute fix. Signing into Claude with GitHub is not the same as installing the app. Go to https://github.com/apps/claude/installations/new , pick the account that owns your repo, choose All repositories, click Install, then reload claude.ai/code. Your repo will be there.
⭐ The single most likely problem today. If you see it three times, tell Sunny immediately.
WHAT'S THE LINK · where are the steps · what page is she on · can I follow along
Here is the workshop page with all the steps on it: https://sunnysink.github.io/ai-forge/workshop/ . Keep it open beside the video and you can follow along at your own pace.
⭐ Expect this constantly. Paste it freely, and paste it again for latecomers.
CAN'T FIND CONTINUE ON THE WEB · it wants me to download · do I need VS Code
You do not need to download anything. On that first screen, scroll past Download for Windows, Terminal and VS Code. Underneath all of it there is a line that says you want to set up apps later, continue on the web. That is the one you want.
It sits below the download options and is very easy to miss.

PRIVATE OR PUBLIC · I made it public · did I do it wrong
Private. If you already made it public you can change it: go to the repo, Settings, scroll to the bottom, Change repository visibility, make it private. Worth doing before you put anything real in there, because your offers, prices and notes end up in these files.
Sunny did this exact thing yesterday. Nobody should feel silly about it.

BRANCH LIST EMPTY · Pages won't deploy · nothing to select
A brand new empty repo has no branch yet, so there is nothing for Pages to publish. Easiest fix is to tick Add a README file when you create the repo. If it already exists, add any file to it and the main branch will appear.
Only comes up if she gets to the publishing part.
IT MADE A BRANCH · weird branch name · my files aren't on main
You can ignore that branch, it is harmless. Your files are going to main, which is what matters, and the instruction file in the template is what makes sure of it.
Confirmed harmless in testing. Do not let anyone rabbit-hole on it.
